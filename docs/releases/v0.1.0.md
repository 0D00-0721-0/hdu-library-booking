# v0.1.0 · 自动登录与模块化发布版

HDU 图书馆预约工具提供命令行和本机网页操作，支持定时预约、备选座位、查询、取消、签到、续座与结果复核。

## 本次更新

- 新增 `--login` 和网页“登录并获取 Cookie”。用户在独立浏览器中完成登录后，工具自动只读校验并保存 Cookie，无需手动复制。失败、超时或取消保留原登录态。
- 按职责拆分核心业务与网页后端，HTML、CSS、JavaScript 独立维护，原启动命令保持可用。
- 补齐请求来源、CSRF、JSON 请求限制及非本机监听密码检查，统一配置与参数校验。
- 移除 Cloudflare Tunnel 功能；完善安装、使用、结构与验证说明。

## 自动获取 Cookie

```bash
python -m pip install -r requirements-login.txt
python instant_book.py --login
```

优先使用已安装的 Chrome；没有可用浏览器时执行 `python -m playwright install chromium`。首次使用先按 README 复制配置，在官方登录窗口完成登录或验证码；工具不自动输入密码。

## 升级注意

- 保留原 `config.yaml`，对照模板检查后运行 `--check-config`。
- 自动登录成功后，配置会引用 `cookies/` 下的新文件绝对路径，并清空旧内联 Cookie 与固定用户信息；原预约计划保持不变。移动项目后重新登录或调整路径。
- 非法重试次数、预留时间和数值会提前报错，布尔值必须使用正确类型。
- 服务升级或重启后刷新网页。自定义网页 API 客户端需要携带 Origin、CSRF 令牌和正确 JSON。
- 自定义 Python 脚本从 `libcs` 对应模块导入，见[项目结构](../architecture.md)。

## 验证与限制

具体环境和测试范围见[验证记录](../verification.md)。浏览器集成测试使用模拟页面和响应，不能替代真实账号登录或当前官方服务的真实预约验证。服务重启不恢复任务，定时运行需要电脑保持唤醒。
