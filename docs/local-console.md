# 本机网页控制台

[返回首页](../README.md)

## 启动与退出

在项目目录激活虚拟环境，运行 `python web_app.py --open`。macOS 也可以双击 `start_web.command`。默认地址是 `http://127.0.0.1:8765`；端口占用时会尝试后续端口，以终端显示的地址为准。

默认只监听本机。按 `Ctrl+C` 停止服务；定时任务期间保持电脑唤醒、终端运行。

## 页面操作保护

保存、预约、停止、取消、签到和续座请求必须来自当前控制台页面。服务重启后，旧页面的操作会提示刷新。页面自动携带操作令牌，无需手动配置。

无密码时只接受本机 Host；非本机监听必须设置 `HDU_WEB_PASSWORD`，防止意外开放无认证服务。项目不提供公网通道启动功能。

## 自定义客户端

自行编写本机客户端时，先读取控制台页面，并在操作请求中携带匹配的 `Origin`、`X-CSRF-Token` 和 `Content-Type: application/json`。JSON 顶层必须是对象，字段不得重复，请求体最多 64 KiB，不支持分块上传。保存或开始预约时必须明确提供布尔类型的 `dry_run`。

## 已知限制

控制台是单人使用的本地工具。任务状态保存在进程内存中，关闭服务后不会自动恢复；日志保存在 `logs/`。Mac 睡眠、系统时钟变化或网络中断可能影响定时任务。服务重启后刷新页面，并先通过官方预约列表核对结果。

## 登录并获取 Cookie

安装 `requirements-login.txt` 后，点击页面顶部“登录并获取 Cookie”，在弹出的浏览器窗口完成登录。成功后自动保存 Cookie 并刷新预约列表；整个任务通过原有日志和状态轮询展示，可用“停止任务”取消。该操作只允许来自本机的连接，浏览器打开在运行服务器的电脑上。

登录与预约、自动签到任务共用任务互斥，避免执行预约时更换凭据。未安装依赖、缺少浏览器、超时或窗口关闭时会给出提示，原登录态保留。详细步骤见[配置与登录态](configuration.md)。
